# Street Fighters Crew — Shop V6

## Что сделано

- Добавлена фирменная PNG-заглушка товара: `assets/no-photo.png`.
- Если у товара нет фотографий, карточка и галерея автоматически показывают эту заглушку.
- Первая фотография из `images` используется как главная на карточке.
- При открытии карточки первая фотография показывается крупно.
- Если фотографий несколько, их можно листать стрелками и выбирать миниатюры.
- Нажатие на крупную фотографию открывает полноэкранный просмотр.
- Видео и размерная сетка уже предусмотрены в структуре товара.

## Как добавить фотографии самому

Для каждого товара есть своя папка в:

`assets/products/`

Например для худи:

`assets/products/13-call-police-hoodie/`

Положите туда:

- `main.jpg` — главная фотография;
- `02.jpg` — вторая фотография;
- `03.jpg` — третья фотография;
- и т.д.

После этого откройте `script.js` и найдите нужный товар.

Было:

`images:[]`

Станет:

`images:[
  "assets/products/13-call-police-hoodie/main.jpg",
  "assets/products/13-call-police-hoodie/02.jpg",
  "assets/products/13-call-police-hoodie/03.jpg"
]`

Порядок файлов в этом массиве = порядок фотографий в галерее. Первая фотография (`main.jpg`) будет главной на карточке и первой при открытии.

### Если фотографий нет

Оставляйте:

`images:[]`

Тогда сайт автоматически покажет:

`assets/no-photo.png`

### Форматы

Для фотографий лучше использовать `.jpg`, `.jpeg`, `.png` или `.webp`.

## Видео

Видео указывается отдельно:

`video:"assets/products/13-call-police-hoodie/review.mp4"`

Если видео нет:

`video:""`

## Размерная сетка

Для одежды:

`sizeChart:"assets/size-charts/hoodie.jpg"`

Изображение можно открыть на весь экран.

## Важно

Не нужно вставлять фотографии прямо в `index.html`. Все данные о товарах находятся в `script.js`. Позже этот массив можно без изменения интерфейса заменить данными из базы данных и админ-панели.


## V7 — необязательные материалы товара

У каждого товара теперь есть три независимых поля:

```js
images: [
  "assets/products/13-call-police-hoodie/main.jpg",
  "assets/products/13-call-police-hoodie/02.jpg"
],
video: "assets/products/13-call-police-hoodie/video.mp4",
sizes: ["S", "M", "L", "XL", "XXL"],
sizeChart: "assets/products/13-call-police-hoodie/size-chart.jpg"
```

Все поля необязательны:
- `images: []` → используется фирменная заглушка «ФОТОГРАФИИ НЕТ».
- `video: null` → блок «ВИДЕО ОБЗОР» не показывается.
- `sizes: []` → блок размеров не показывается.
- `sizeChart: null` → блок «РАЗМЕРНАЯ СЕТКА» не показывается.

### Как добавить новому товару видео
1. Положить MP4 в папку конкретного товара.
2. В `script.js` указать путь в поле `video`.

### Как добавить размерную сетку
1. Положить JPG/PNG в папку товара.
2. Указать путь в `sizeChart`.
3. Если размерная сетка товару не нужна — оставить `sizeChart: null`.

Карточка товара автоматически показывает только те возможности, которые заполнены.
